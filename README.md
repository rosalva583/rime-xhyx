# rime-xhyx

xhyx (小鶴音形) schema for rime.



This is the xhyx (小鶴音形) rime schema.

## How to Use

Just download the yaml files, and copys them to your rime user data directorary.



And modify your `default.custom.yaml` file to add the schema.

On windows, it's easier, just download the zip file and you can import into your user data directorary through `settings`.
